This is the honest gap in the survey, and the other session may already have the answer.
Run this on the Mac with the drive mounted to close it:
source ./reimage.env

for c in "$REIMAGE_ARTIFACT_ROOT"/*/ "$REIMAGE_ARTIFACT_ROOT"/reimaged-system/*/; do
  [ -d "$c" ] || continue
  if [ -d "${c}runs" ]; then
    printf 'indexed      %s\n' "$c"
  else
    printf 'NOT indexed  %s\n' "$c"
  fi
done
Then, per indexed category, see whether any run is missing a row:
./bin/reindex-artifact-runs.sh --category "$REIMAGE_ARTIFACT_ROOT/<category>" --dry-run
--dry-run prints the rows it would add and writes nothing. Rows are inserted in completion order rather than appended, because officialness for a latest-wins point is the last matching row in file order — appending a recovered older run below a newer one would make the older one official.
