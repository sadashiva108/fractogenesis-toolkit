## Three things this session read and never recorded

Each is a reading with no finding behind it. They are listed so they are not
lost, and **they are not claims until someone writes them up.**

- **Markdown link targets `[text](path)` are validated nowhere.**
  `verify-doc-paths.sh` does scan `docs/` — this session said otherwise, tested it
  wrong twice, and retracted; `0036` is genuinely resolved. What is actually
  uncovered is relative links, which is `0044`'s mechanism from the other side.
- **`root()` in `plan_findings_work.py` self-locates by walking up to a directory
  named `docs`.** Every relocation proposal has to answer that line, and the
  commission does not mention it.
- **`updatedAt` is written in two zones.** Across the 62 `metadata.json` files
  some values carry `+00:00` and some `-04:00`, so the field sorts correctly only
  because the offsets are both present and honoured — and nothing checks that a
  write moves it forward. This revision found a bundle stamped five minutes ahead
  of the tree's next-latest value and had to pick a later wall-clock time by hand.
- **`docs/sessions/session-responsibilities.md` is a dated 2026-09-01 record that
  says of itself that it is not maintained**, while `docs/sessions/INDEX.md` calls
  it *the boundary between concurrent sessions* and says to update it when work
  changes hands. Three sessions now run concurrently and the boundary lives in
  their prompts instead. It was deliberately not edited here.
