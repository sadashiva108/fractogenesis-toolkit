# secrets-patterns.txt
#
# Optional and opt-in. If this file exists at
#   $REIMAGE_ARTIFACT_ROOT/gitignore-superset/secrets-patterns.txt
# backup-repos.sh passes it to every --selected-* run automatically (no flag).
# Files matching these patterns are DIVERTED into <stage>/secrets-candidates/
# (e.g. dryrun/secrets-candidates/, live/secrets-candidates/) instead of the
# ordinary output tree, so a credential-shaped file never sits next to regular
# staged files or syncs to cloud storage unreviewed. Same format and matching
# engine as backup-exclude-list.txt.
#
# It DIVERTS, it does not drop: a diverted file is still copied (to
# secrets-candidates/) under --selected-copy, just segregated for review.
# Diverting something harmless costs you one review line; missing something
# credential-shaped costs you a plaintext secret on the drive. Prefer to divert.

.env
